# Assignment 2

## Overview

This repository contains a C++ program and algorithm designed to find all prime numbers between two given integer values (inclusive) using nested loops and modular arithmetic.

## Description

The program takes two inputs representing a range (start_num and end_num) and outputs every prime number within that range. It handles edge cases such as numbers less than 2 and optimizes the prime checking process by evaluating divisors only up to the square root of the target number.
